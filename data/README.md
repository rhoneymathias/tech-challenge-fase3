# Data

Esta pasta contém as informações sobre as fontes de dados utilizadas no projeto Tech Challenge – Fase 3, desenvolvido a partir das pesquisas State of Data Brasil.

Fonte dos dados

Os dados utilizados no projeto são provenientes da pesquisa State of Data Brasil, realizada pela comunidade Data Hackers, em parceria com organizações como Bain & Company e Vector nas edições mais recentes.

As pesquisas disponibilizam dados anonimizados para a comunidade e têm como objetivo mapear o mercado brasileiro de dados e Inteligência Artificial.

Edições utilizadas
Edição	Descrição
2023	State of Data Brasil 2022–2023
2024	State of Data Brasil 2024–2025
2025–2026	State of Data Brasil 2025–2026

Os dados foram utilizados a partir das edições de 2023, 2024 e 2025-2026 e processados no pipeline desenvolvido em AWS.
